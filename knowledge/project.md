# Expense Tracker Project

## Project Vision

Expense Tracker is a modern personal finance application.

The goal is NOT simply to record income and expenses.

The goal is to help users understand, manage and improve their financial life.

---

## Core Modules

A core module is one the application ships today and can be reached by name.

| Module | Where it lives |
|---|---|
| Dashboard | Tab bar, labelled **Home** |
| Income | Tab bar |
| Expenses | Tab bar |
| Analytics | Tab bar — the chart, calendar heatmap, stats and category breakdown |
| Budget Planning | More → Budget Planning; the Expenses screen in Planned mode |
| Salary Calculator | More |
| Settings | More |

Savings Goals also ships, under More. It is not listed above because it is not
part of the stated vision; it is a feature of it.

**Reports** was listed here and was never built. Nothing in the application
produces a report and no product definition of one exists, so the entry
described an intention rather than a module. It has moved to Long-term Vision,
where the other unbuilt intentions already live. Every module named above now
has a destination, and that is the property this section is meant to hold.

---

## Project Principles

The application must be

- Fast
- Simple
- Offline-first
- Mobile-friendly
- Easy to understand
- Reliable

---

## Target Users

People with little accounting knowledge.

Every screen should be understandable without training.
